# 建設業経理士1級 学習アプリ

スマホのブラウザで使う、建設業経理士1級の学習用アプリです。
ホーム画面に追加すると、電波のない場所でも使えます。学習の記録はスマホの中だけに保存されます。

---

## 1. スマホで使い始める

### iPhone（Safari）
1. Safari で公開URL（例：`https://ユーザー名.github.io/kk1-app/`）を開く
2. 画面下の共有ボタン（□に↑のマーク）を押す
3. 「ホーム画面に追加」→「追加」を押す
4. 次からは、ホーム画面のアイコンから起動する

> **大切**：iPhone では、ホーム画面に追加しないまましばらく使わずにいると、学習の記録が消えることがあります。必ずホーム画面に追加してから使ってください。

### Android（Chrome）
1. Chrome で公開URLを開く
2. 案内の「ホーム画面に追加」を押す（出ないときは右上の「⋮」→「ホーム画面に追加」）

### 記録のバックアップ
- 機種変更やブラウザのデータ消去に備えて、**週に1回**は「設定」→「記録を書き出す」でバックアップしてください。
- 7日以上書き出していないと、ホームと設定に案内が出ます。
- 戻すときは「設定」→「記録を読み込む」で、書き出したファイルを選びます。

## 2. 問題を追加・修正する

問題は `questions` フォルダの JSON ファイルに入っています。

| ファイル | 科目 |
|---|---|
| `questions/zaimu.json` | 財務諸表 |
| `questions/bunseki.json` | 財務分析 |
| `questions/genka.json` | 原価計算 |

### 手順
1. メモ帳ではなく、**VS Code**（無料）などのテキストエディタでファイルを開く
2. 最後の問題の `}` のあとに `,`（半角カンマ）を付け、下のひな形を貼り付けて書き換える
3. 保存したら、下の「4. 変更をチェックする」を行う
4. 「3. 公開する」の「更新するとき」の手順でアップロードする

### ひな形（形式ごと）

**一問一答（flash）**
```json
{
  "id": "zaimu-011",
  "subject": "財務諸表",
  "topic": "税効果会計",
  "type": "flash",
  "difficulty": 1,
  "question": "問題文",
  "answer": "答え",
  "explanation": "解説"
}
```

**4択（choice）**：`answer` には正解の**番号**を書きます。1つ目が 0、2つ目が 1、3つ目が 2、4つ目が 3 です。
```json
{
  "id": "zaimu-012",
  "subject": "財務諸表",
  "topic": "リース",
  "type": "choice",
  "difficulty": 2,
  "question": "問題文",
  "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  "answer": 2,
  "explanation": "解説"
}
```

**計算（calc）**：`verify` は答えの検算用です。`expr` に計算式、`expected` に答えの数値を書きます。
```json
{
  "id": "genka-011",
  "subject": "原価計算",
  "topic": "CVP分析",
  "type": "calc",
  "difficulty": 2,
  "question": "問題文",
  "hint": "ヒント",
  "steps": ["手順1", "手順2", "手順3"],
  "answer": "損益分岐点完成工事高 400,000千円",
  "explanation": "解説",
  "verify": { "expr": "120000/(1-0.7)", "expected": 400000 }
}
```
答えが複数あるときは、`verify` を `[ {…}, {…} ]` のように並べます。

**論述（essay）**
```json
{
  "id": "bunseki-011",
  "subject": "財務分析",
  "topic": "安全性",
  "type": "essay",
  "difficulty": 3,
  "question": "問題文",
  "keywords": ["キーワード1", "キーワード2"],
  "answer": "模範解答の要旨",
  "explanation": "解説"
}
```

### 書き方の決まり
- `id` は**ほかの問題と重ならない**名前にします（科目の英字＋連番。例：`zaimu-011`）。一度使った id は変えないでください。変えると、その問題の学習記録が引き継がれません。
- `difficulty` は 1（基本）・2（標準）・3（応用）のどれかです。
- 問題文の中で改行するときは `\n` と書きます。
- 文字の `"` を使うときは `\"` と書きます。
- `topic`（論点）は、同じ論点なら**一字一句同じ名前**にします。違う名前にすると、別の論点として集計されます。
- 自信のない内容には、解説に【要確認】と書いておきます。

### 新しい科目を足すとき
1. `questions` に新しい JSON ファイル（例：`kessan.json`）を作る（中身は `[ ]` で囲んだ問題の並び）
2. `questions/index.json` の `files` にファイル名を足す
   ```json
   { "files": ["zaimu.json", "bunseki.json", "genka.json", "kessan.json"] }
   ```
3. `sw.js` の `CACHE_VERSION` の数字を1つ上げる（オフライン用の保存内容を新しくするため）

## 3. 公開する（GitHub Pages・無料）

### 初回
1. https://github.com にログインし、右上の「＋」→「New repository」
2. Repository name に `kk1-app`（好きな英数字でよい）と入れ、**Public** を選んで「Create repository」
3. 作ったリポジトリの画面で「uploading an existing file」を押す
4. このフォルダの中身をドラッグ＆ドロップする。**入れないもの**：`_check`・`_backup` フォルダと `設計書.md`
   - フォルダごとドラッグすれば、`js`・`questions` などのフォルダの形のままアップロードされます
5. 「Commit changes」を押す
6. 「Settings」→ 左の「Pages」→ Branch を **main**、フォルダを **/(root)** にして「Save」
7. 1〜2分待つと、`https://ユーザー名.github.io/kk1-app/` で開けるようになる

### 更新するとき
1. リポジトリの画面で「Add file」→「Upload files」
2. 変更したファイルを、**同じ場所に**ドラッグ＆ドロップ（同じ名前のファイルは上書きされます）
   - `questions/zaimu.json` を直したときは、`questions` フォルダごとドラッグする
3. 「Commit changes」を押す
4. 1〜2分後、スマホでアプリを開き直す。問題ファイルの変更は、ネットにつながっていれば自動で反映されます
   - `index.html`・`style.css`・`js` の中身・`sw.js` を変えたときは、`sw.js` の `CACHE_VERSION` を1つ上げてからアップロードします。アプリの画面下に「新しい版があります」と出たら、タップすると更新されます。

> 公開したアプリは、URLを知っていれば誰でも開けます。学習記録はスマホの中だけにあり、公開されません。

## 4. 変更をチェックする（任意・PCに Node.js がある場合）

このフォルダでコマンドを実行します。

```
node tools/validate.js      … 問題ファイルの形式チェック（id の重複、項目の書き忘れなど）
node tools/verify-calc.js   … 計算問題の答えの検算
node --test tests/          … 復習間隔の計算のテスト
```

すべて「エラー0件」「不一致0件」「fail 0」なら問題ありません。
チェックをしなくても、形式の誤りがある問題は読み飛ばされ、「設定」→「データの問題」に表示されます。アプリが止まることはありません。

---

## 5. PCで動作を確かめる（任意）

```
python -m http.server 8000
```
を実行し、ブラウザで http://localhost:8000/ を開きます。ファイルを直接ダブルクリックして開いても動きません。
